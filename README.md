# fabula-bench

fabula-bench is a set of interactive, text-based adventures for an agent to explore. Each adventure is a causal world that holds several plots. The agent plays it, pieces together what it finds, solves the adventure's mystery and explains it — that is, it presents a plot.

The agent under test needs nothing but the adventure and, if it wants one, a scratchpad for its intermediate results.

How the adventures are written is described in [docs/developer.md](docs/developer.md).
